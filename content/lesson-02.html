2.1Functions

Many quantities depend on other quantities. The area of a circle depends on its radius. Your load balance depends on how many texts you send. The brightness of a star, as seen from Earth, depends on its distance from us. In each case there is a rule that takes one number and gives back another. That rule is called a function, and it is the most important idea in all of precalculus and calculus.

Definition A function \(f\) is a rule that assigns to each element \(x\) in a set \(A\) exactly one element, called \(f(x)\), in a set \(B\). The set \(A\) is the domain of \(f\) (all possible inputs). The range of \(f\) is the set of all possible values of \(f(x)\) as \(x\) varies through the domain (all possible outputs).

Function notation. If a function is given by the formula \(y = f(x)\), then \(x\) is the independent variable (the input) and \(y\) is the dependent variable (the output). We read \(f(x)\) as "\(f\) of \(x\)". Take note: \(f(x)\) does not mean \(f\) times \(x\). It is the output of \(f\) when the input is \(x\).

It helps to picture a function as a machine: we feed in \(x\), the machine follows its rule, and out comes \(f(x)\). Another picture is the mapping (arrow) diagram, where an arrow joins each input to its output (see Figure 2.1). The rule "exactly one output" means exactly one arrow leaves each input. Two arrows may land on the same output, and that is fine.

Evaluating a function. To evaluate, we replace \(x\) by the given input everywhere in the formula, using parentheses. For example, if \(f(x) = x^2 - 2x\), then

\[ f(-3) = (-3)^2 - 2(-3) = 9 + 6 = 15. \]

The input does not have to be a number. It can be an expression, like \(a\), \(-a\) or \(a + h\). Then \(f(a + h) = (a + h)^2 - 2(a + h)\). We will use this to build the difference quotient, which measures how fast \(f\) changes, and which you will meet again in calculus.

Key equations
\[ \text{net change in } f \text{ from } x = a \text{ to } x = b \;=\; f(b) - f(a) \]
\[ \text{difference quotient: } \quad \frac{f(a + h) - f(a)}{h}, \qquad h \ne 0 \]

Net change. The net change tells us how much the output changed overall. Let \(f(x) = x^2\). From \(x = 1\) to \(x = 3\), the net change is \(f(3) - f(1) = 9 - 1 = 8\). From \(x = -2\) to \(x = 2\), it is \(f(2) - f(-2) = 4 - 4 = 0\). A net change of 0 does not mean nothing happened: the values went down to 0 and then came back up to 4.

The domain of a function. When a function is given by a formula and no domain is stated, the domain is the set of all real numbers for which the formula makes sense. Recall the two rules from Module 1: we cannot divide by zero, and we cannot take an even root of a negative number. For example:

  • \(f(x) = \dfrac{1}{x^2 - x}\): we need \(x^2 - x = x(x - 1) \ne 0\), so the domain is \(\{x \mid x \ne 0 \text{ and } x \ne 1\}\).
  • \(g(x) = \sqrt{9 - x^2}\): we need \(9 - x^2 \ge 0\), so \(x^2 \le 9\), and the domain is \([-3, 3]\).
  • \(h(t) = \dfrac{t}{\sqrt{t + 1}}\): the root needs \(t + 1 \ge 0\), and it is in the denominator, so \(t + 1 \gt 0\). The domain is \((-1, \infty)\).

Four ways to represent a function. A function can be described verbally ("the cost is ₱15 per kilo"), algebraically (\(C(x) = 15x\)), visually (a graph) or numerically (a table of values). Good problem solvers move freely between these four.

Take note \(f(a + h)\) is not \(f(a) + h\), and it is not \(f(a) + f(h)\). With \(f(x) = x^2\): \(f(2 + 1) = 9\), but \(f(2) + 1 = 5\) and \(f(2) + f(1) = 5\). Always substitute the whole expression \(a + h\) inside parentheses.

2.2Graphs of Functions

A formula tells us exactly what a function does, but a graph lets us see it all at once: where it rises, where it falls, where it crosses the axes. The most important way to picture a function is through its graph.

Definition If \(f\) is a function with domain \(A\), then the graph of \(f\) is the set of ordered pairs \(\{(x, f(x)) \mid x \in A\}\). In other words, the graph of \(f\) is the graph of the equation \(y = f(x)\). The height of the graph above the point \(x\) is the value \(f(x)\).

Graphing by plotting points. The simplest method: make a table of values, plot the points, and join them with a smooth curve. For \(f(x) = x^2\) we get \((-2, 4), (-1, 1), (0, 0), (1, 1), (2, 4)\), a parabola. For \(g(x) = x^3\) and \(h(x) = \sqrt{x}\) we do the same (see Figure 2.2). Take note that \(h\) only accepts \(x \ge 0\), so its graph starts at the origin.

A family of power functions. Functions of the form \(f(x) = x^n\) are called power functions. Let's compare a few in Desmos: graph \(x^2, x^4, x^6\) in the viewing rectangle \([-2, 2]\) by \([-1, 3]\), and \(x, x^3, x^5\) in \([-2, 2]\) by \([-2, 2]\) (see Figure 2.3). Two patterns appear. When \(n\) is even, the graph looks like the parabola \(y = x^2\). When \(n\) is odd, it looks like \(y = x^3\). And as \(n\) grows, the graph becomes flatter near 0 and steeper when \(|x| \gt 1\). All of them pass through \((1, 1)\).

Piecewise defined functions use different formulas on different parts of the domain. For example, \(f(x) = \begin{cases} x^2 & x \le 1 \\ 2x + 1 & x \gt 1 \end{cases}\). To evaluate, we first decide which piece the input belongs to: \(f(-2) = 4\) (first piece) and \(f(3) = 7\) (second piece). To graph, we draw each piece only over its own interval, using a solid dot for an included endpoint and an open dot for an excluded one. The most famous piecewise function is the absolute value: \(|x| = x\) if \(x \ge 0\) and \(|x| = -x\) if \(x \lt 0\).

The Vertical Line Test A curve in the coordinate plane is the graph of a function if and only if no vertical line intersects the curve more than once.

Why does this work? Each vertical line \(x = a\) represents one input. If the line hits the curve twice, the input \(a\) has two outputs, which a function is not allowed to have (see Figure 2.4). The circle \(x^2 + y^2 = 4\) fails the test: the line \(x = 1\) meets it at \((1, \sqrt3)\) and \((1, -\sqrt3)\). Algebraically, solving for \(y\) gives \(y = \pm\sqrt{4 - x^2}\), two outputs for one input.

Relations and functions. A relation is any collection of ordered pairs \((x, y)\); the \(x\)-values are inputs and the \(y\)-values are outputs. A relation is a function if every input corresponds to exactly one output. So \(\{(1, 5), (2, 5), (3, 7)\}\) is a function, but \(\{(1, 5), (1, 6), (3, 7)\}\) is not, because the input 1 has two outputs.

Take note Repeated outputs are allowed; repeated inputs with different outputs are not. Students often reject \(\{(1, 5), (2, 5)\}\) because "5 appears twice". It is a function: each input still has only one output.

2.3Getting Information from the Graph of a Function

Once we have a graph, we can read off a lot without any more algebra. The value \(f(a)\) is the height of the graph at \(x = a\). The domain is the set of \(x\)-values the graph covers (its "shadow" on the \(x\)-axis), and the range is the set of \(y\)-values it covers (its shadow on the \(y\)-axis). The \(x\)-intercepts are the zeros of \(f\), the solutions of \(f(x) = 0\), and the \(y\)-intercept is \(f(0)\).

A graph is also a quick way to solve equations and inequalities: the solutions of \(f(x) = g(x)\) are the \(x\)-coordinates of the points where the two graphs meet, and \(f(x) \gt g(x)\) holds where the graph of \(f\) is above the graph of \(g\). In Desmos, click on an intersection point to read its coordinates.

Definition A function \(f\) is increasing on an interval \(I\) if \(f(x_1) \lt f(x_2)\) whenever \(x_1 \lt x_2\) in \(I\). It is decreasing on \(I\) if \(f(x_1) \gt f(x_2)\) whenever \(x_1 \lt x_2\) in \(I\).

The value \(f(a)\) is a local maximum value of \(f\) if \(f(a) \ge f(x)\) for all \(x\) near \(a\); we say \(f\) has a local maximum at \(x = a\). The value \(f(b)\) is a local minimum value if \(f(b) \le f(x)\) for all \(x\) near \(b\).

In plain words: increasing means the graph rises as we move from left to right, decreasing means it falls. A local maximum is the top of a "hill" and a local minimum is the bottom of a "valley". Look at Figure 2.5 for \(f(x) = x^3 - 3x\). It rises until \(x = -1\), falls from \(x = -1\) to \(x = 1\), and then rises again. So it has a local maximum value \(f(-1) = -1 + 3 = 2\) and a local minimum value \(f(1) = 1 - 3 = -2\).

End behavior. We also ask what happens far to the left and far to the right. For \(x^3 - 3x\), the values become huge and positive as \(x \to \infty\), and huge and negative as \(x \to -\infty\). Some graphs instead level off toward a horizontal line, or shoot up near a vertical line; these lines are called asymptotes. For example, \(y = \dfrac{1}{x}\) gets close to the \(x\)-axis as \(|x|\) grows, and it blows up near \(x = 0\). We will study asymptotes carefully with rational functions in Module 3.

Take note Intervals of increase and decrease are intervals of \(x\)-values, not \(y\)-values. For Figure 2.5 the answer "decreasing on \([-2, 2]\)" (the heights) is wrong; the correct answer is \([-1, 1]\). Likewise, the local maximum value is the height 2, and it occurs at \(x = -1\).

2.4Average Rate of Change of a Function

Functions describe change. Suppose a jeepney travels 12 km in the first 30 minutes of a trip and only 3 km in the next 30 minutes because of EDSA traffic. Its average speed was much higher in the first half hour. Average speed is a special case of a more general idea: the average rate of change.

Definition The average rate of change of the function \(y = f(x)\) between \(x = a\) and \(x = b\) is
\[ \text{average rate of change} = \frac{\text{change in } y}{\text{change in } x} = \frac{f(b) - f(a)}{b - a}. \]
It is the slope of the secant line through the points \((a, f(a))\) and \((b, f(b))\) on the graph of \(f\).

Notice that the top of the fraction is exactly the net change from Section 2.1. We divide it by the length of the interval to get change per unit of input. Its units are "output units per input unit": metres per second, pesos per kilo, degrees per hour.

Let's try one. For \(f(x) = \tfrac12 x^2 + 1\) between \(x = 1\) and \(x = 4\):

\[ \frac{f(4) - f(1)}{4 - 1} = \frac{9 - 1.5}{3} = \frac{7.5}{3} = 2.5. \]

On the graph, this is the slope of the secant line joining \((1, 1.5)\) and \((4, 9)\): it rises 7.5 units over a run of 3 units (see Figure 2.6).

If the average rate of change is positive, \(f\) went up overall on the interval; if negative, it went down. For a curve like this one, the average rate of change is different on different intervals: from \(x = 0\) to \(x = 1\) it is only \(\dfrac{1.5 - 1}{1} = 0.5\). The graph gets steeper as we move right, so the secant slopes grow.

Over a general interval from \(a\) to \(a + h\), the average rate of change is \(\dfrac{f(a + h) - f(a)}{h}\), our difference quotient. In calculus, you will let \(h\) shrink to 0 and the secant line will turn into a tangent line. That is the beginning of the derivative.

Take note Keep the same order on top and bottom. \(\dfrac{f(b) - f(a)}{b - a}\) is correct, and so is \(\dfrac{f(a) - f(b)}{a - b}\). But \(\dfrac{f(b) - f(a)}{a - b}\) has the wrong sign. Also, do not divide by \(b - a\) when the question asks only for the net change.

2.5Linear Functions and Models

In Section 2.4 we saw that most functions have different average rates of change on different intervals. There is one family whose rate of change never changes: the linear functions. Their graphs are straight lines, and they are the simplest and most common models in science and business.

Definition A linear function is a function of the form \(f(x) = ax + b\). Its graph is a line with slope \(a\) and \(y\)-intercept \(b\). The average rate of change of a linear function has the constant value \(a\) between any two points:
\[ a = \text{slope of the graph of } f = \text{rate of change of } f. \]

Identifying linear functions. A function is linear if we can rewrite it as \(ax + b\), where \(x\) appears only to the first power, with no products of \(x\) with itself, no \(x\) in a denominator and no \(x\) under a root. For example, \(f(x) = 7 - \tfrac12 x\) is linear with \(a = -\tfrac12\) and \(b = 7\), but \(g(x) = \dfrac{3}{x}\) and \(h(x) = \sqrt{x} + 1\) are not.

The rate of change is the slope. Let's check it. For \(f(x) = ax + b\) and any two inputs \(x_1 \ne x_2\):

\[ \frac{f(x_2) - f(x_1)}{x_2 - x_1} = \frac{(ax_2 + b) - (ax_1 + b)}{x_2 - x_1} = \frac{a(x_2 - x_1)}{x_2 - x_1} = a. \]

So when \(x\) increases by 1, \(f(x)\) always changes by \(a\). This is how we spot linear data in a table: equal steps in \(x\) give equal steps in \(y\).

Making linear models. Suppose a water tank at a barangay hall holds 50 L and a pump adds 12 L per minute. After \(t\) minutes the tank holds \(V(t) = 50 + 12t\) litres. The rate of change 12 L/min is the slope, and the starting amount 50 L is the \(V\)-intercept. After 15 minutes, \(V(15) = 50 + 180 = 230\) L. When a problem gives two data points instead, we first compute the slope \(a = \dfrac{y_2 - y_1}{x_2 - x_1}\) and then find \(b\) from one of the points (see Figure 2.7 and Example 2.8).

Take note Write the model in the form \(ax + b\) before naming \(a\) and \(b\). In \(g(x) = 3(1 - 2x)\) the slope is not 3 and not \(-2\): expanding gives \(g(x) = -6x + 3\), so \(a = -6\) and \(b = 3\). And \(x(4 + 3x) = 3x^2 + 4x\) is not linear even though no \(x^2\) is visible at first.

2.6Transformations of Functions

If we know the graph of a basic function such as \(x^2\), \(x^3\), \(\sqrt{x}\) or \(|x|\), we can draw many related graphs with almost no work by moving, flipping and stretching it. This is one of the best places to use Desmos: type y = a(x - h)^2 + k, let Desmos create sliders for \(a\), \(h\) and \(k\), and watch what each parameter does to the parabola.

Key equations Let \(c \gt 0\).
\[ y = f(x) + c:\ \text{shift up } c \qquad y = f(x) - c:\ \text{shift down } c \]
\[ y = f(x - c):\ \text{shift right } c \qquad y = f(x + c):\ \text{shift left } c \]
\[ y = -f(x):\ \text{reflect about the } x\text{-axis} \qquad y = f(-x):\ \text{reflect about the } y\text{-axis} \]
\[ y = c\,f(x):\ \text{vertical stretch by } c \ (c \gt 1), \ \text{shrink by } c \ (0 \lt c \lt 1) \]
\[ y = f(cx):\ \text{horizontal shrink by } \tfrac{1}{c} \ (c \gt 1), \ \text{stretch by } \tfrac{1}{c} \ (0 \lt c \lt 1) \]

Shifts. Adding \(c\) outside the function adds \(c\) to every height, so the graph moves up. A change inside works backwards: \(y = (x - 2)^2\) reaches its lowest value when \(x - 2 = 0\), that is at \(x = 2\), so the graph moved right 2 (see Figure 2.8, top left).

Reflections. \(y = -f(x)\) turns every height into its opposite, flipping the graph over the \(x\)-axis. For example, \(y = -x^2\) is a parabola opening downward. \(y = f(-x)\) flips it over the \(y\)-axis. For example, \(g(x) = \sqrt{-x}\) is only defined when \(-x \ge 0\), so its domain is \(\{x \mid x \le 0\}\) and its graph points to the left (Figure 2.8, top right).

Stretching and shrinking. \(y = 3x^2\) multiplies every height by 3, so the parabola looks narrower; \(y = \tfrac13 x^2\) looks wider. Horizontally the effect is again reversed: \(y = f(2x)\) reaches each height at half the \(x\)-value, so the graph is squeezed toward the \(y\)-axis by a factor of \(\tfrac12\) (Figure 2.8, bottom).

When several transformations are combined, let's follow the order of operations on \(x\): first the change inside, then stretch and reflection, then the shift outside. For \(y = 2(x + 1)^2 - 3\), we start from \(x^2\), shift left 1, stretch vertically by 2, and shift down 3. The vertex moves from \((0, 0)\) to \((-1, -3)\).

Even and odd functions Let \(f\) be a function. Then \(f\) is even if \(f(-x) = f(x)\) for every \(x\) in its domain; its graph is symmetric about the \(y\)-axis. And \(f\) is odd if \(f(-x) = -f(x)\) for every \(x\) in its domain; its graph is symmetric about the origin.

The names come from the power functions: \(x^2, x^4, x^6\) are even, and \(x, x^3, x^5\) are odd (look again at Figure 2.3). To test a function, we replace \(x\) by \(-x\) and simplify. For \(f(x) = x^3 - 3x\): \(f(-x) = -x^3 + 3x = -(x^3 - 3x) = -f(x)\), so it is odd, and indeed Figure 2.5 looks the same after a half turn about the origin. In transformation language: an even function is unchanged by reflection about the \(y\)-axis.

Take note The inside shift goes against the sign. \(y = (x + 4)^2\) moves the graph left 4, not right. And most functions are neither even nor odd: \(h(x) = 2x - x^2\) gives \(h(-x) = -2x - x^2\), which is neither \(h(x)\) nor \(-h(x)\).

2.7One-to-One Functions and Their Inverses

The inverse of a function "undoes" what the function does. If \(f\) converts Celsius to Fahrenheit, its inverse converts Fahrenheit back to Celsius. To talk about undoing, we first need a way to apply one function after another, called composition.

Definition Given two functions \(f\) and \(g\), the composition \(f \circ g\) is the function defined by
\[ (f \circ g)(x) = f\big(g(x)\big). \]
The domain of \(f \circ g\) is the set of all \(x\) in the domain of \(g\) such that \(g(x)\) is in the domain of \(f\).

We read \(f \circ g\) as "\(f\) composed with \(g\)", and we apply \(g\) first. For example, with \(f(x) = \sqrt{x}\) and \(g(x) = x + 5\), we have \((f \circ g)(x) = \sqrt{x + 5}\) (domain \([-5, \infty)\)) but \((g \circ f)(x) = \sqrt{x} + 5\) (domain \([0, \infty)\)). Usually \(f \circ g \ne g \circ f\).

One-to-one and the Horizontal Line Test A function \(f\) with domain \(A\) is one-to-one if no two elements of \(A\) have the same image, that is,
\[ f(x_1) \ne f(x_2) \quad \text{whenever} \quad x_1 \ne x_2. \]
A function is one-to-one if and only if no horizontal line intersects its graph more than once.

The function \(f(x) = x^2\) is not one-to-one, because \(f(-\sqrt2) = f(\sqrt2) = 2\): the line \(y = 2\) hits the parabola twice (see Figure 2.9, left). But \(f(x) = 2x + 1\) is one-to-one: if \(x_1 \ne x_2\) then \(2x_1 + 1 \ne 2x_2 + 1\). Why does this matter? A function that sends two inputs to the same output cannot be undone, because we would not know which input to go back to.

Definition Let \(f\) be a one-to-one function with domain \(A\) and range \(B\). Its inverse function \(f^{-1}\) has domain \(B\) and range \(A\) and is defined by
\[ f^{-1}(y) = x \iff f(x) = y. \]
The functions \(f\) and \(f^{-1}\) satisfy the cancellation equations:
\[ f^{-1}\big(f(x)\big) = x \ \text{ for every } x \text{ in } A, \qquad f\big(f^{-1}(x)\big) = x \ \text{ for every } x \text{ in } B. \]

How to find the inverse of a one-to-one function. (1) Write \(y = f(x)\). (2) Solve this equation for \(x\) in terms of \(y\) (if possible). (3) Interchange \(x\) and \(y\); the resulting equation is \(y = f^{-1}(x)\). Some books swap first and solve second; both give the same answer. For \(f(x) = 2x + 1\):

\[ y = 2x + 1 \;\Rightarrow\; y - 1 = 2x \;\Rightarrow\; x = \frac{y - 1}{2} \;\Rightarrow\; f^{-1}(x) = \frac{x - 1}{2}. \]

Check with the cancellation equation: \(f^{-1}(f(x)) = \dfrac{(2x + 1) - 1}{2} = x\). Good. Since \(f(1) = 3\), we get \(f^{-1}(3) = 1\). In general, if \((a, b)\) is on the graph of \(f\), then \((b, a)\) is on the graph of \(f^{-1}\). That is why the graph of \(f^{-1}\) is the reflection of the graph of \(f\) in the line \(y = x\) (Figure 2.9, right). Try it in Desmos: graph \(f\), \(f^{-1}\) and \(y = x\) together.

A function that is not one-to-one can sometimes be made one-to-one by restricting its domain. The function \(x^2 + 3\) fails the Horizontal Line Test on \(\mathbb{R}\), but on the domain \(x \ge 0\) it passes, and then it has an inverse (Example 2.12).

Take note The \(-1\) in \(f^{-1}\) is not an exponent: \(f^{-1}(x) \ne \dfrac{1}{f(x)}\). For \(f(x) = 2x + 1\), \(f^{-1}(3) = 1\), while \(\dfrac{1}{f(3)} = \dfrac17\). Also, \(f \circ g\) means substitution, not multiplication: \(f(g(x)) \ne f(x) \cdot g(x)\).

★Key takeaways

  • A function assigns exactly one output f(x) to each input x. To evaluate, substitute the whole input in parentheses; f(a + h) is not f(a) + h.
  • The domain of a formula is every x where it makes sense: no zero denominators and no even roots of negative numbers. Net change is f(b) − f(a).
  • The graph of f is the graph of y = f(x). A curve is a function's graph exactly when it passes the Vertical Line Test. Even powers look like x², odd powers like x³.
  • From a graph, read values, domain, range, zeros, where f increases or decreases (intervals of x), local maxima and minima, and end behavior.
  • Average rate of change = (f(b) − f(a))/(b − a) = slope of the secant line. It is constant exactly for linear functions f(x) = ax + b, where it equals the slope a.
  • f(x) + c shifts up, f(x − c) shifts right, −f(x) and f(−x) reflect, c f(x) stretches vertically, f(cx) shrinks horizontally (c > 1). Even: f(−x) = f(x); odd: f(−x) = −f(x).
  • (f ∘ g)(x) = f(g(x)), apply g first. A one-to-one function (Horizontal Line Test) has an inverse; find it by solving y = f(x) for x and swapping, then check f⁻¹(f(x)) = x. The graph of f⁻¹ is the mirror image of f in y = x.

Example 2.1 Evaluating a function and net change

Let \(f(x) = 3x^2 + x - 5\). Evaluate (a) \(f(-2)\), (b) \(f(0)\), (c) \(f(4)\), (d) \(f\!\left(\tfrac12\right)\). Then find the net change in \(f\) from \(x = 0\) to \(x = 4\).

(SRW, Functions)
Show solution (try it first)
Given
  • \(f(x) = 3x^2 + x - 5\).
  • Asked: four function values, and the net change \(f(4) - f(0)\).
Step 1: Substitute x = −2

Let's replace every \(x\) with \((-2)\), keeping the parentheses.

\[f(-2) = 3(-2)^2 + (-2) - 5\]

\[= 3(4) - 2 - 5\]

\[= 12 - 7 = 5\]

Step 2: Substitute x = 0 and x = 4

\[f(0) = 3(0)^2 + 0 - 5 = -5\]

\[f(4) = 3(4)^2 + 4 - 5\]

\[= 48 + 4 - 5 = 47\]

Step 3: Substitute x = 1/2

Take note: \(\left(\tfrac12\right)^2 = \tfrac14\), so we square first, then multiply by 3.

\[f\!\left(\tfrac12\right) = 3\left(\tfrac12\right)^2 + \tfrac12 - 5\]

\[= \tfrac34 + \tfrac24 - \tfrac{20}{4}\]

\[= -\tfrac{15}{4}\]

Step 4: Net change from 0 to 4

\[\text{net change} = f(4) - f(0)\]

\[= 47 - (-5) = 52\]

Answer

\(f(-2) = 5\), \(f(0) = -5\), \(f(4) = 47\), \(f\!\left(\tfrac12\right) = -\tfrac{15}{4}\). The net change from \(x = 0\) to \(x = 4\) is \(52\).

Check

In Desmos, type f(x)=3x^2+x-5 and then f(-2), f(1/2): it shows 5 and \(-3.75 = -\tfrac{15}{4}\). A common slip is \(3(-2)^2 = -12\): the square makes it positive.

If \(f(x) = 2x^2 + 3x - 1\), evaluate (a) \(f(a)\), (b) \(f(-a)\), (c) \(f(a + h)\), (d) \(\dfrac{f(a + h) - f(a)}{h}\), \(h \ne 0\).

(SRW, Functions)
Show solution (try it first)
Given
  • \(f(x) = 2x^2 + 3x - 1\).
  • Asked: \(f\) at the inputs \(a\), \(-a\), \(a + h\), and the difference quotient.
Step 1: f(a) and f(−a)

Replace \(x\) by \(a\), then by \((-a)\).

\[f(a) = 2a^2 + 3a - 1\]

\[f(-a) = 2(-a)^2 + 3(-a) - 1\]

\[= 2a^2 - 3a - 1\]

Take note: \((-a)^2 = a^2\), so the first term stays positive.

Step 2: f(a + h)

Replace \(x\) by \((a + h)\) and expand \((a + h)^2 = a^2 + 2ah + h^2\).

\[f(a + h) = 2(a + h)^2 + 3(a + h) - 1\]

\[= 2(a^2 + 2ah + h^2) + 3a + 3h - 1\]

\[= 2a^2 + 4ah + 2h^2 + 3a + 3h - 1\]

Step 3: Subtract f(a)

\[f(a + h) - f(a) = (2a^2 + 4ah + 2h^2 + 3a + 3h - 1) - (2a^2 + 3a - 1)\]

\[= 4ah + 2h^2 + 3h\]

Step 4: Divide by h

Every term has a factor \(h\), so we factor it out and cancel (allowed since \(h \ne 0\)).

\[\frac{f(a + h) - f(a)}{h} = \frac{h(4a + 2h + 3)}{h}\]

\[= 4a + 2h + 3\]

Answer

(a) \(2a^2 + 3a - 1\); (b) \(2a^2 - 3a - 1\); (c) \(2a^2 + 4ah + 2h^2 + 3a + 3h - 1\); (d) \(4a + 2h + 3\).

Check

Try \(a = 1\), \(h = 1\): \(f(2) = 8 + 6 - 1 = 13\) and \(f(1) = 4\), so \(\dfrac{13 - 4}{1} = 9\). The formula gives \(4(1) + 2(1) + 3 = 9\). It matches.

Example 2.3 A mobile data plan (piecewise function)

A prepaid data promo costs ₱299 a month and includes 10 GB. Each extra gigabyte costs ₱50. (a) Write the monthly cost \(C(x)\) as a piecewise function of the data used, \(x\) GB. (b) Find \(C(8)\), \(C(10)\) and \(C(14)\). (c) Describe the graph of \(C\) and give its range for \(0 \le x \le 20\).

(SRW, Graphs of Functions)
Show solution (try it first)
Given
  • Fixed cost ₱299 for up to 10 GB.
  • ₱50 for each GB above 10.
  • Asked: a formula for \(C(x)\), three values, and the graph and range on \([0, 20]\).
Step 1: Build the two pieces

If \(0 \le x \le 10\), the user pays only ₱299. If \(x \gt 10\), the extra data is \(x - 10\) GB, costing \(50(x - 10)\) more.

\[C(x) = \begin{cases} 299 & 0 \le x \le 10 \\ 299 + 50(x - 10) & x \gt 10 \end{cases}\]

Step 2: Evaluate (choose the piece first)

8 and 10 belong to the first piece; 14 belongs to the second.

\[C(8) = 299, \qquad C(10) = 299\]

\[C(14) = 299 + 50(14 - 10)\]

\[= 299 + 200 = 499\]

Step 3: Graph and range

On \([0, 10]\) the graph is a horizontal segment at height 299. For \(x \gt 10\) it is a line of slope 50 starting at \((10, 299)\). At \(x = 20\):

\[C(20) = 299 + 50(10) = 799\]

The pieces join at \((10, 299)\), so the graph has no gap, and the heights cover every value from 299 to 799.

Answer

(a) \(C(x) = 299\) for \(0 \le x \le 10\) and \(C(x) = 299 + 50(x - 10)\) for \(x \gt 10\). (b) \(C(8) = \text{₱}299\), \(C(10) = \text{₱}299\), \(C(14) = \text{₱}499\). (c) A flat segment then a rising line; the range on \([0, 20]\) is \([299, 799]\).

Check

14 GB is 4 GB over the limit, and \(4 \times 50 = 200\) extra pesos. In Desmos, type C(x)={0<=x<=10:299, x>10:299+50(x-10)} to see the graph.

Example 2.4 Reading a graph: x³ − 3x

Graph \(f(x) = x^3 - 3x\) (Figure 2.5, or Desmos). (a) Find the zeros and the \(y\)-intercept. (b) Find the local maximum and minimum values. (c) State the intervals on which \(f\) is increasing and decreasing. (d) Describe the end behavior and give the range.

(SRW, Getting Information from the Graph of a Function)
Show solution (try it first)
Given
  • \(f(x) = x^3 - 3x\), domain all real numbers.
  • From the graph: a hill at \(x = -1\) and a valley at \(x = 1\).
  • Asked: intercepts, local extrema, intervals of increase and decrease, end behavior, range.
Step 1: Zeros and y-intercept

Set \(f(x) = 0\) and factor.

\[x^3 - 3x = 0\]

\[x(x^2 - 3) = 0\]

\[x = 0 \quad \text{or} \quad x = \pm\sqrt3\]

The \(y\)-intercept is \(f(0) = 0\).

Step 2: Local maximum and minimum values

The graph turns at \(x = -1\) and \(x = 1\). Let's compute the heights there.

\[f(-1) = (-1)^3 - 3(-1) = -1 + 3 = 2\]

\[f(1) = 1^3 - 3(1) = 1 - 3 = -2\]

Step 3: Increasing and decreasing

Reading left to right: the graph rises up to \(x = -1\), falls between \(x = -1\) and \(x = 1\), and rises after \(x = 1\).

Step 4: End behavior and range

For large positive \(x\) the term \(x^3\) dominates, so \(f(x) \to \infty\) as \(x \to \infty\), and \(f(x) \to -\infty\) as \(x \to -\infty\). Since the graph is unbroken and goes from \(-\infty\) to \(\infty\), it takes every real value.

Answer

(a) Zeros \(-\sqrt3, 0, \sqrt3\); \(y\)-intercept 0. (b) Local maximum value 2 at \(x = -1\); local minimum value \(-2\) at \(x = 1\). (c) Increasing on \((-\infty, -1]\) and \([1, \infty)\); decreasing on \([-1, 1]\). (d) \(f(x) \to \pm\infty\) as \(x \to \pm\infty\); range \((-\infty, \infty)\).

Check

Near \(x = -1\): \(f(-1.1) = -1.331 + 3.3 = 1.969\) and \(f(-0.9) = -0.729 + 2.7 = 1.971\), both less than 2. So 2 really is a local maximum value. Notice the local maximum is not the largest value overall: \(f(3) = 18\).

Example 2.5 Average rate of change on different intervals

For \(f(x) = (x - 3)^2\), find the average rate of change (a) between \(x = 1\) and \(x = 3\), (b) between \(x = 4\) and \(x = 7\), and (c) between \(x = a\) and \(x = a + h\).

(SRW, Average Rate of Change of a Function)
Show solution (try it first)
Given
  • \(f(x) = (x - 3)^2\).
  • Asked: \(\dfrac{f(b) - f(a)}{b - a}\) on \([1, 3]\), \([4, 7]\) and \([a, a + h]\).
Step 1: Between 1 and 3

\[f(1) = (1 - 3)^2 = 4, \qquad f(3) = 0\]

\[\frac{f(3) - f(1)}{3 - 1} = \frac{0 - 4}{2} = -2\]

Step 2: Between 4 and 7

\[f(4) = 1, \qquad f(7) = 16\]

\[\frac{f(7) - f(4)}{7 - 4} = \frac{16 - 1}{3} = 5\]

Step 3: Between a and a + h

Let's expand both squares. Write \(u = a - 3\), so \(f(a) = u^2\) and \(f(a + h) = (u + h)^2\).

\[f(a + h) - f(a) = (u + h)^2 - u^2\]

\[= u^2 + 2uh + h^2 - u^2 = 2uh + h^2\]

\[\frac{f(a + h) - f(a)}{h} = 2u + h = 2(a - 3) + h\]

\[= 2a - 6 + h\]

Answer

(a) \(-2\) (the function decreases on average); (b) \(5\) (it increases on average); (c) \(2a - 6 + h\).

Check

Put \(a = 4\), \(h = 3\) in part (c): \(2(4) - 6 + 3 = 5\), the same as part (b). And \(a = 1\), \(h = 2\): \(2 - 6 + 2 = -2\), the same as part (a).

Example 2.6 Dropping a hammer on the Moon

An astronaut drops a hammer from rest on the Moon. The distance it has fallen after \(t\) seconds is \(d(t) = 0.81t^2\) metres. Find the average speed of the hammer (a) during the first 2 seconds, (b) between \(t = 2\) and \(t = 4\). What do the answers tell us?

(SRW, Average Rate of Change of a Function)
Show solution (try it first)
Given
  • \(d(t) = 0.81t^2\) m (the Moon's gravity is about \(1.62\ \text{m/s}^2\), and \(\tfrac12 \cdot 1.62 = 0.81\)).
  • Asked: average speed = average rate of change of \(d\) on \([0, 2]\) and \([2, 4]\).
Step 1: Distances at t = 0, 2, 4

\[d(0) = 0\]

\[d(2) = 0.81(4) = 3.24 \text{ m}\]

\[d(4) = 0.81(16) = 12.96 \text{ m}\]

Step 2: Average speed on [0, 2]

\[\frac{d(2) - d(0)}{2 - 0} = \frac{3.24}{2} = 1.62 \text{ m/s}\]

Step 3: Average speed on [2, 4]

\[\frac{d(4) - d(2)}{4 - 2} = \frac{12.96 - 3.24}{2}\]

\[= \frac{9.72}{2} = 4.86 \text{ m/s}\]

Answer

(a) 1.62 m/s; (b) 4.86 m/s. The average speed is three times larger in the second interval, so the hammer is speeding up as it falls. A function whose average rate of change grows like this has a graph that bends upward.

Check

Units: metres divided by seconds give m/s. For comparison, on Earth \(d(t) \approx 4.9t^2\), and the average speed on \([0, 2]\) would be \(9.8\) m/s, about six times faster, since Earth's gravity is about six times the Moon's.

Example 2.7 Identifying linear functions

Decide whether each function is linear. If it is, write it as \(f(x) = ax + b\) and state \(a\) and \(b\). (a) \(f(x) = 2 + 3x\) (b) \(g(x) = 3(1 - 2x)\) (c) \(h(x) = x(4 + 3x)\) (d) \(k(x) = \dfrac{1 - 5x}{4}\)

(SRW, Linear Functions and Models)
Show solution (try it first)
Given
  • Four formulas.
  • Asked: which ones can be written as \(ax + b\), and the values of \(a\) and \(b\).
Step 1: f and g

Reorder \(f\), and distribute in \(g\).

\[f(x) = 3x + 2 \;\Rightarrow\; a = 3,\ b = 2\]

\[g(x) = 3 - 6x = -6x + 3 \;\Rightarrow\; a = -6,\ b = 3\]

Step 2: h

Distribute and look at the powers of \(x\).

\[h(x) = 4x + 3x^2\]

There is an \(x^2\) term, so \(h\) is not linear (it is quadratic).

Step 3: k

Split the fraction.

\[k(x) = \frac14 - \frac54 x = -\frac54 x + \frac14\]

\[a = -\tfrac54,\ b = \tfrac14\]

Answer

(a) Linear, \(a = 3\), \(b = 2\). (b) Linear, \(a = -6\), \(b = 3\). (c) Not linear. (d) Linear, \(a = -\tfrac54\), \(b = \tfrac14\).

Check

For \(g\): \(g(0) = 3\), \(g(1) = -3\), \(g(2) = -9\). Each step of 1 in \(x\) changes \(g\) by \(-6\), a constant rate. For \(h\): \(h(0) = 0\), \(h(1) = 7\), \(h(2) = 20\); the steps 7 and 13 are not equal, so \(h\) is not linear.

Example 2.8 A weather balloon (linear model)

A PAGASA weather balloon is launched from Manila on a day when the ground temperature is 30 °C. At an altitude of 2 km the balloon reads 17 °C. Assume the temperature \(T\) is a linear function of the altitude \(h\) (in km). (a) Find \(T(h)\). (b) Interpret the slope. (c) Predict the temperature at 5 km. (d) At what altitude does the temperature reach 0 °C?

(SRW, Linear Functions and Models)
Show solution (try it first)
Given
  • Two data points: \((h, T) = (0, 30)\) and \((2, 17)\).
  • \(T(h) = ah + b\).
  • Asked: the formula, the meaning of \(a\), \(T(5)\), and \(h\) when \(T = 0\).
Step 1: Slope (rate of change)

\[a = \frac{17 - 30}{2 - 0} = \frac{-13}{2} = -6.5\]

Step 2: Intercept and model

At \(h = 0\) the temperature is 30, so \(b = 30\).

\[T(h) = 30 - 6.5h\]

Step 3: Predict at 5 km

\[T(5) = 30 - 6.5(5)\]

\[= 30 - 32.5 = -2.5\ ^\circ\text{C}\]

Step 4: Altitude where T = 0

\[30 - 6.5h = 0\]

\[6.5h = 30\]

\[h = \frac{30}{6.5} \approx 4.62 \text{ km}\]

Answer

(a) \(T(h) = 30 - 6.5h\). (b) The temperature drops 6.5 °C for every kilometre of altitude. (c) About \(-2.5\) °C at 5 km. (d) About 4.62 km (see Figure 2.7).

Check

\(T(2) = 30 - 13 = 17\), matching the data. The model only makes sense in the lower atmosphere (roughly the first 10 to 15 km); a linear model should not be pushed far beyond its data.

Example 2.9 Combining transformations

Explain how to obtain the graph of \(y = -2\sqrt{x + 3} + 1\) from the graph of \(y = \sqrt{x}\). Then state its domain and range.

(SRW, Transformations of Functions)
Show solution (try it first)
Given
  • Basic graph \(y = \sqrt{x}\): starts at \((0, 0)\), domain \([0, \infty)\), range \([0, \infty)\).
  • New function \(y = -2\sqrt{x + 3} + 1\).
  • Asked: the transformations, domain and range.
Step 1: Inside change (horizontal shift)

Replacing \(x\) by \(x + 3\) shifts the graph left 3. The starting point moves to \((-3, 0)\).

\[y = \sqrt{x + 3}\]

Step 2: Stretch and reflect

The factor 2 stretches vertically by 2; the minus sign reflects about the \(x\)-axis, so the graph now goes down.

\[y = -2\sqrt{x + 3}\]

Step 3: Outside change (vertical shift)

Adding 1 shifts the graph up 1. The starting point moves to \((-3, 1)\).

\[y = -2\sqrt{x + 3} + 1\]

Step 4: Domain and range

The root needs \(x + 3 \ge 0\), so \(x \ge -3\). Since \(\sqrt{x + 3} \ge 0\), we have \(-2\sqrt{x + 3} \le 0\), so \(y \le 1\).

Answer

Shift left 3, stretch vertically by a factor of 2, reflect about the \(x\)-axis, shift up 1. Domain \([-3, \infty)\); range \((-\infty, 1]\).

Check

At \(x = 1\): \(-2\sqrt4 + 1 = -3\). On \(y = \sqrt{x}\), the point \((4, 2)\) should move to \((4 - 3, -2 \cdot 2 + 1) = (1, -3)\). It matches.

Example 2.10 Even, odd or neither?

Determine whether each function is even, odd or neither: (a) \(f(x) = x^5 + x\), (b) \(g(x) = 1 - x^4\), (c) \(h(x) = 2x - x^2\).

(SRW, Transformations of Functions)
Show solution (try it first)
Given
  • Three polynomials.
  • Test: compute \(f(-x)\) and compare with \(f(x)\) and \(-f(x)\).
Step 1: f(x) = x⁵ + x

\[f(-x) = (-x)^5 + (-x)\]

\[= -x^5 - x\]

\[= -(x^5 + x) = -f(x)\]

Step 2: g(x) = 1 − x⁴

\[g(-x) = 1 - (-x)^4\]

\[= 1 - x^4 = g(x)\]

Step 3: h(x) = 2x − x²

\[h(-x) = 2(-x) - (-x)^2 = -2x - x^2\]

Compare: \(h(x) = 2x - x^2\) and \(-h(x) = -2x + x^2\). Neither matches \(-2x - x^2\).

Answer

(a) \(f\) is odd (symmetric about the origin). (b) \(g\) is even (symmetric about the \(y\)-axis). (c) \(h\) is neither.

Check

Numbers: \(f(1) = 2\), \(f(-1) = -2\) (opposites); \(g(2) = -15 = g(-2)\) (equal); \(h(1) = 1\), \(h(-1) = -3\) (neither). One numerical test can rule out "even" or "odd", but to prove a function is even or odd we need the algebra for every \(x\).

Example 2.11 Composition of functions

Let \(f(x) = x^2\) and \(g(x) = x - 3\). (a) Find \(f \circ g\) and \(g \circ f\). (b) Find \((f \circ g)(5)\) and \((g \circ f)(7)\).

(SRW, One-to-One Functions and Their Inverses)
Show solution (try it first)
Given
  • \(f(x) = x^2\) and \(g(x) = x - 3\), both with domain \(\mathbb{R}\).
  • Asked: both compositions and two values.
Step 1: f ∘ g (apply g first)

\[(f \circ g)(x) = f\big(g(x)\big) = f(x - 3)\]

\[= (x - 3)^2\]

Step 2: g ∘ f (apply f first)

\[(g \circ f)(x) = g\big(f(x)\big) = g(x^2)\]

\[= x^2 - 3\]

Step 3: The two values

\[(f \circ g)(5) = (5 - 3)^2 = 4\]

\[(g \circ f)(7) = 7^2 - 3 = 46\]

Answer

(a) \((f \circ g)(x) = (x - 3)^2\) and \((g \circ f)(x) = x^2 - 3\); both have domain \(\mathbb{R}\). (b) \((f \circ g)(5) = 4\) and \((g \circ f)(7) = 46\).

Check

Step by step: \(g(5) = 2\), then \(f(2) = 4\). And \(f(7) = 49\), then \(g(49) = 46\). Notice \(f \circ g\) and \(g \circ f\) are different functions: order matters.

Example 2.12 Finding and verifying inverses

(a) Show that \(f(x) = x^2 + 3\) is not one-to-one on \(\mathbb{R}\), then find the inverse of \(f\) on the restricted domain \(x \ge 0\). (b) Find the inverse of \(g(x) = \dfrac{2x + 3}{x - 1}\) and verify it with a cancellation equation.

(SRW, One-to-One Functions and Their Inverses)
Show solution (try it first)
Given
  • \(f(x) = x^2 + 3\); restricted domain \([0, \infty)\), so its range is \([3, \infty)\).
  • \(g(x) = \dfrac{2x + 3}{x - 1}\), \(x \ne 1\).
  • Asked: \(f^{-1}\), \(g^{-1}\), and a check.
Step 1: f is not one-to-one on ℝ

Two different inputs give the same output:

\[f(-1) = 1 + 3 = 4 = f(1)\]

So the horizontal line \(y = 4\) meets the graph twice. On \(x \ge 0\) only the right half of the parabola remains, which passes the Horizontal Line Test.

Step 2: Solve y = x² + 3 for x

\[y = x^2 + 3\]

\[x^2 = y - 3\]

\[x = \sqrt{y - 3}\]

Take note: we keep only the positive root because \(x \ge 0\).

Interchange \(x\) and \(y\):

\[f^{-1}(x) = \sqrt{x - 3}, \quad x \ge 3\]

Step 3: Solve y = (2x + 3)/(x − 1) for x

Multiply both sides by \(x - 1\) and collect the \(x\)-terms on one side.

\[y(x - 1) = 2x + 3\]

\[xy - y = 2x + 3\]

\[xy - 2x = y + 3\]

\[x(y - 2) = y + 3\]

\[x = \frac{y + 3}{y - 2}\]

Interchange \(x\) and \(y\):

\[g^{-1}(x) = \frac{x + 3}{x - 2}\]

Step 4: Verify g⁻¹(g(x)) = x

\[g^{-1}\big(g(x)\big) = \frac{\dfrac{2x + 3}{x - 1} + 3}{\dfrac{2x + 3}{x - 1} - 2}\]

Multiply the top and bottom by \(x - 1\):

\[= \frac{(2x + 3) + 3(x - 1)}{(2x + 3) - 2(x - 1)}\]

\[= \frac{5x}{5} = x\]

Answer

(a) \(f(-1) = f(1) = 4\), so \(f\) is not one-to-one on \(\mathbb{R}\); on \(x \ge 0\), \(f^{-1}(x) = \sqrt{x - 3}\) with domain \([3, \infty)\). (b) \(g^{-1}(x) = \dfrac{x + 3}{x - 2}\), and \(g^{-1}(g(x)) = x\).

Check

\(f(2) = 7\) and \(f^{-1}(7) = \sqrt{4} = 2\). \(g(3) = \dfrac{9}{2}\) and \(g^{-1}\!\left(\tfrac92\right) = \dfrac{7.5}{2.5} = 3\). Both return the starting input.
